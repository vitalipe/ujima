# Terminology

## Site

A **site** is a physical deployment location such as:

- a school computer room
- a library
- a community center

A site may contain multiple UjimaOS machines connected through a local network.

## Circle

A **circle** is the set of visible UjimaOS peers on a local network.

Circles are intentionally simple:

- no central coordinator
- no required management server
- local peer discovery only

The current implementation uses local network peer discovery and assumes a mostly trusted local environment.
