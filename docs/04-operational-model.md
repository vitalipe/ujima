# Operational Model

## Hardware

The current baseline deployment target is:

- Raspberry Pi 5
- 2GB RAM (4GB recommended for multitasking)
- 32GB SD card minimum

Typical deployments are expected to contain between 3 and 12 machines, though larger deployments of roughly 32 systems are considered feasible depending on network quality.

## Network Requirements

A basic deployment requires:

- a Wi-Fi router
- DHCP enabled
- wireless client isolation disabled

No central server is required.

Optional external USB or SATA storage devices may host shared offline educational content such as:

- offline Wikipedia
- Khan Academy content
- local web resources
- Internet-in-a-Box resources

UjimaOS itself does not require these services to function.
