# Applications and Content

## Applications

Applications are distributed primarily as AppImage files.

Applications may be:

- preinstalled
- copied from USB storage
- distributed across peers through the administration interface

The administration system can:

- install applications
- remove applications
- show or hide applications in the launcher

## Offline Content

UjimaOS distinguishes between applications and resources.

Resources may include:

- offline educational websites
- local Wikipedia mirrors
- Internet-in-a-Box resources
- local web services

Resources are treated primarily as URLs.

The system includes a Chromium-based browser operating in guest mode, and administrators can create launchers pointing to local or remote educational resources.

This allows lightweight integration with systems such as Internet-in-a-Box without tightly coupling UjimaOS to a specific content platform.
