# Future Goals

Planned future directions include:

- USB-backed persistent user profiles with portable personal storage
- richer classroom management
- local Wi-Fi AP deployment support
- peer-assisted content distribution
- local and cloud AI integration
- improved offline synchronization
- richer content management systems

The project is also evaluating appliance-style operating system bases such as ChromiumOS or related systems for future versions.

The current Linux-based implementation was chosen primarily to allow rapid iteration and validation of core concepts including:

- peer-managed administration
- USB-token workflows
- local-first operation
- rollback-safe updates
- lightweight classroom management
